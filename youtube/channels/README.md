Shorts — внутри каждого канала: 3 в неделю, нарезка из своих длинных выпусков.

## Нагрузка на ПК (RTX 5070)

8 длинных выпусков в неделю × ~4–7 часов = **~35–50 часов работы ПК в неделю**. Реально, если ПК рендерит ночами и
днём, когда свободен. Если не успевает — первые 2–3 недели выпускать по 1 ролику в неделю на канал (порядок: сначала
пилоты всех четырёх, затем по графику).

## Порядок запуска

1. Модели: `python download_models.py D:\ComfyUI_windows_portable studio --source modelscope` (картинки + музыка).
2. Тест голосов: немецкий (сделан, Whisper 0.90–1.00), испанский — сделать перед пилотом.
3. Каналы создаёт владелец (бренд-аккаунты, подтверждение по телефону — без него нельзя роликам > 15 мин).
4. Пилоты: сценарий → проверка фактов → голос → кадры → анимации → музыка → сборка → просмотр владельцем → публикация.

Оформление всех каналов: `_brand/make_brand.py` (аватар 800×800, баннер 2560×1440, шаблон обложки 1280×720).
