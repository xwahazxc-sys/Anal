# Лиды для управления правами на YouTube: фильмы с неофициальными копиями

Источник: twins*_result.json (поиск YouTube, только полные копии 60+ мин). Ручная чистка: убраны обзоры, совместные
просмотры, официальные каналы и чужие видео с похожим названием (детские мультфильмы, музыка, другие фильмы).
«Копий» — сколько разных каналов выложили фильм (признак частых перезаливов). «Сумма» — просмотры всех найденных
копий: это доход, который правообладатель недополучает. Дат загрузки нет: YouTube не пустил серверы GitHub на
страницы видео, поэтому «долго держится» оценено косвенно — по накопленным просмотрам.
Какие копии действительно не авторизованы, подтверждает только правообладатель.
