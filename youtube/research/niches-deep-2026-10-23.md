# Глубокая разведка ниш: 5 длинных (25+ мин) + 5 Shorts — 23.10.2026

## Как собрано

- **Длинные:** 241 поисковый запрос (30 типов ниш × 12 языков: EN, DE, FR, NL, NO, DA, SV, FI, IT, ES, JA, KO), фильтр
  YouTube «этот месяц + длиннее 20 минут + по просмотрам». Полные данные (исходный язык звука, подписчики, дата) — по 777
  топовым роликам; последние 90 роликов — по 900 каналам; дата создания — по 930 каналам (страница «О канале»).
- **Shorts:** 3 420 популярных Shorts из 96 хэштегов на тех же языках; дата и канал — по 735 роликам; вкладка Shorts — по
  389 каналам.
- **Метрики:** спрос (медиана просмотров топа), доля родного языка, доля крупных каналов (500k+), прорывы маленьких
  каналов (<50k) и молодых (<1 года), кратность к медиане своего канала (метод `/yt-viral` swipe.py), RPM языка и темы.
- **Ограничения:** YouTube включил проверку «не бот» после ~1 500 полных запросов, поэтому полные данные есть примерно по
  половине роликов (в обход со входом в аккаунт не шли). Ленты Shorts по хэштегам глобальные — немецкие/французские
  хэштеги выдают в основном чужой контент, поэтому по Shorts вывод сделан для EN и ES. RPM — оценки третьих сторон.
