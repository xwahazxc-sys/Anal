## Шаг 0 — библиотека персонажей (один раз, 2–3 ч)

Это главный инструмент канала: все ролики собираются из неё, и персонажи выглядят одинаково из ролика в ролик.

1. **Референс.** Для каждого персонажа (Barney, Head Nurse, Intern, Tiny Anomaly, Ratthew, Stalker, Secret Agent, Ron, Rattina)
   — одна чёткая картинка во весь рост: скриншот модели персонажа или официальный арт игры. Запись игры для этого не нужна.
2. **6 эмоций (Qwen-Image-Edit, `youtube/lenny/slideshow/v2/wfq.py`):** из референса сделать спокойного, злого, испуганного,
   смеющегося, хитрого и грустного. Промпт: `same character, Roblox style, <emotion> face, full body, plain background`.
   Запуск — `kaggle_comfy_runner.py` на бесплатных 2×T4 Kaggle (30 GPU-часов в неделю).
3. **3–4 фона:** коридор ночью, операционная, ресепшен, палата — сгенерировать через Qwen-Image (`qwen_t2i` в `wfq.py`).
4. Сложить в `youtube/roblox-fantom/library/<персонаж>/<эмоция>.png` и дальше брать только оттуда.

Персонажи принадлежат игре — это фан-контент, как у всех каналов ниши. Свои при этом сцены, шутки, анимация и звук.

## Формат A — «Мем» (одна шутка, 10–20 с)

1. **Шутка (Claude).** Раз в неделю: «дай 10 шуток про персонажей Animal Hospital в формате POV / When… / … be like,
   каждая — 2–4 кадра, поворот в последнем кадре». Источник идей — комментарии и тренды. Берём 3.
2. **Кадры (Qwen-Image-Edit):** персонаж из библиотеки + фон + действие («Barney holding a syrup bottle, guilty face,
   dark hospital corridor»). 2–4 кадра, сразу вертикально.
3. **Оживить (Wan 2.2 I2V, `youtube/lenny/comfy/wf_i2v_14b.py`):** каждый кадр → 3–5 с. Промпт — только движение:
   «slowly turns his head, eyes widen, camera pushes in». Размер в воркфлоу — 480×832 (вертикаль).
4. **Подпись мема:** белая плашка сверху с чёрным текстом («POV: you left the syrup on the desk») — ffmpeg `drawtext` или CapCut.
5. **Звук:** музыка по `music.md` + удары/«vine boom» на повороте (ElevenLabs Sound Effects, тот же ключ, что в `tts.yml`).
6. **Петля:** концовка перетекает в первый кадр:
   ```bash
   python3 youtube/whatif/cuts/recut.py meme.mp4 meme_loop.mp4 9-13 0-9
   ```
7. **Название:** формат шутки + эмодзи («POV: Barney Found the Syrup 🍯»). Проверить `/yt-package`.

## Формат B — «Сериал» (анимация с персонажами, 30–50 с)

Честно: лидеры ниши (Sona Extra 505, Number Band) анимируют в Roblox Studio (Moon Animator). Через ИИ быстрее, но картинка
должна оставаться **узнаваемо роблоксовской** — поэтому всё строим от **библиотеки персонажей** (шаг 0).

1. **Сценарий (Claude, `/yt-script`):** 6–10 кадров по 3–5 с. Кадр 1 — самая сильная картинка. Последний кадр — клиффхэнгер
   или «Ending 1 or 2?». Для каждого кадра: что на экране, подпись (3–6 слов), звук. Формат таблицы — как `timeline.json`
   в `youtube/whatif/stories/sun/2d/`.
2. **Ключевые кадры (Qwen-Image-Edit, `wfq.py`):** берёшь персонажа из библиотеки и правишь позу/костюм/сцену текстом
   («Barney holding a syrup bottle, guilty face, dark hospital corridor, Roblox style»). Сразу вертикально.
3. **Оживление (Wan 2.2 I2V, `wf_i2v_14b.py`):** каждый кадр → клип ~5 с (81 кадр, 16 fps). Промпт — только движение:
   «Barney slowly turns his head, eyes widen, camera pushes in». Для вертикали поменять размер в воркфлоу на 480×832.
   Брак (ломается лицо/руки) — перегенерировать с другим seed, на кадр закладывать 2–3 попытки.
4. **Голос:** в нише много роликов **без речи** — пузыри с текстом + звуки (так дешевле и понятно всему миру). Если нужен голос —
   ElevenLabs через Action «Narration» (`tts.yml`). Сейчас `tts.py` жёстко использует хоррор-диктора (`VOICE = ...`),
   для мультяшных голосов нужно добавить параметр голоса (одна правка; могу сделать). Губы под голос — `wf_s2v.py`.
5. **Звук и музыка:** таймлайн SFX + музыка по `music.md`, сведение как в `mix.py` (громкость −14 LUFS).
6. **Сборка:** ffmpeg (склейка клипов + подписи) или Remotion `Short.tsx` (уже 1080×1920, 30 fps, подписи по словам).
7. **Серийность:** одинаковая обложка-плашка «BARNEY'S NIGHT SHIFT #N», одна и та же музыкальная тема в начале — зритель узнаёт серию за секунду.

## Формат C — «Тренд» (под трендовый трек, 10–20 с)

1. **Найти звук** (воскресенье, см. `content-plan.md`) и сохранить его в приложении YouTube.
2. **Взять 2–4 состояния персонажа** (спокоен / зол / в маске / без маски) из библиотеки; чего нет — доделать через
   Qwen-Image-Edit (`wfq.py`). Можно слегка оживить через Wan I2V.
3. **Смонтировать в бит** (CapCut или ffmpeg) и экспортировать **без музыки** (или с черновым треком только для монтажа).
4. **Загрузить через приложение YouTube на телефоне:** «+» → Short → выбрать видео → «Добавить звук» → сохранённый трендовый звук, выставить отрезок.
   Так музыка идёт по лицензии YouTube и ролик не блокируется. С компьютера (и нашим `uploader.py`) этот шаг сделать нельзя.

## Своя песня (14.11 и дальше)

1. Текст — Claude: куплет про персонажей (Barney, Head Nurse, Tiny Anomaly), простой припев на 4 строки, который хочется повторять.
2. Музыка — ИИ-генератор с правами на коммерческое использование: **Suno или Udio на платном тарифе**, или **ElevenLabs Music**
   (тот же аккаунт ElevenLabs, если тариф позволяет). На бесплатных тарифах права на коммерческое использование обычно не даются — проверить условия перед публикацией.
3. Видео — кадры через Qwen-Image-Edit + Wan I2V, танец/движения в бит.
4. Своя песня = свой звук: другие авторы могут снимать Shorts под него, и каждый такой ролик ведёт ссылкой на канал.

## Загрузка и расписание

- **Вручную (проще для старта):** Studio → «Создать» → загрузить → «Запланировать» на время из плана. Форматы C — только с телефона (см. выше).
- **Автоматически (A и B, если в них нет трендового звука):** в репо есть `uploader.py` + Action «YouTube upload»: ролики из `queue.json` грузятся по расписанию
  с закреплённым комментарием. Для этого канала нужно: свои секреты `<ПРЕФИКС>_COOKIES` и `<ПРЕФИКС>_PROXY` в настройках репо
  и папка `youtube/roblox-fantom/publish/queue.json`; в `yt-upload.yml` сейчас прописаны только Lenny и What If — нужна правка. Пока не подключено.
- **Лимит загрузок:** у неподтверждённого канала маленький дневной лимит (это уже ловили на What If 23.10).
  Подтвердить канал по телефону: youtube.com/verify.

## Неделя производства (пример, ~10–13 ч)

Генерация на Kaggle идёт фоном: запустил пачку кадров/клипов — занимаешься другим.

| День | Что | Время |
|---|---|---|
| Вс | Разбор недели (15 мин) + поиск тренда + 10 шуток и 2 сценария B от Claude, выбор | ~1,5 ч |
| Пн | Кадры для 3 × A и 2 × B одной пачкой (Qwen на Kaggle, фоном) + отбор | ~2 ч |
| Вт | Оживление всех кадров одной пачкой (Wan на Kaggle, фоном) + отбор брака | ~2 ч |
| Ср | Сборка 3 × A: подписи, звук, петля | ~2 ч |
| Чт | Сборка 2 × B: звук, подписи, сведение | ~2,5 ч |
| Пт | 2 × C (позы из библиотеки, монтаж в бит, загрузка с телефона) + планирование A/B, закрепы, ответы на комменты (`/yt-comment`) | ~2 ч |
