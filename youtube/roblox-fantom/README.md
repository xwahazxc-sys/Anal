## 2. Главная проблема (одна)

**Канал стоит на чужом контенте.** Это сразу три риска:
1. **Монетизация:** YouTube отклоняет партнёрку за «повторно используемый контент» (reused content), даже при 1 000+ подписчиков.
2. **Страйки:** любой автор TikTok из нарезки может подать жалобу, три страйка — удаление канала.
3. **Рост:** алгоритм видит в нарезках один и тот же материал. #5 и #6 получили в 50 раз меньше #4.
   Почему именно — точно не скажу (данных Studio нет), но совпадение по времени с затуханием
   всех геймплейных каналов ниши в конце июля (см. ниже) — вероятная причина.

**Что делать на этой неделе:** перестать выпускать чужие клипы и начать **свои Shorts** по плану из `content-plan.md`.
Старые шесть видео можно оставить, но новых нарезок чужого не делать. Если придёт претензия — удалить ролик, не спорить.
