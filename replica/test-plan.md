# Test plan

Что запускается: `cd app && npm run typecheck && npm run test:unit && npm run test:e2e` (для e2e сначала `npx expo export --platform web` и раздача `dist/` на порту 8099). Тесты идут по локальным демо-данным, не по оригинальному приложению.

## Случаи по потокам

F01 Проверить продукт
- H1 штрихкод хорошего продукта даёт зелёную оценку (e2e). H2 плохой продукт показывает альтернативы (e2e).
- E1 один продукт дважды — одна запись в истории. E2 история переживает перезагрузку. E3 дефисы в штрихкоде игнорируются. E4 Enter в поле отправляет форму (клавиатура). E5 высокий риск ограничивает оценку числом 49 (юнит и e2e). E6 раскрытие ингредиента.
- N1 только буквы — сообщение об ошибке. N2 неизвестный штрихкод — экран «нет в базе».

F02 Добавить продукт
- H1 неизвестный штрихкод, форма, продукт найден по тому же коду (e2e). E1 длинное название с эмодзи без горизонтальной прокрутки. E2/E3 двойное нажатие создаёт один продукт. N1 пустая форма — понятная ошибка.

F03 История и избранное
- H1 избранное включается и выключается. H2 списки открываются, пустые состояния есть.

F04 Premium
- H1 бесплатному пользователю поиск ведёт на экран подписки. H2 после тестовой покупки поиск работает, пустой результат даёт сообщение. H3 предпочтение «без лактозы» даёт предупреждение на карточке.

Доступность: правила axe (WCAG 2 A/AA, серьёзные и критические) на экранах сканера, карточки, истории, формы добавления, подписки, обе ширины.

Безопасность (база): второй пользователь ничего не видит и не может писать за первого, `products` не читается напрямую, Premium нельзя выдать себе, подписки пишет только сервер, анонимный доступ закрыт, удаление аккаунта стирает данные.

## Не автоматизировано (нужен человек и устройство)

- Камера, фонарик и считывание штрихкода на iPhone и Android; отказ в разрешении камеры.
- Реальная покупка и восстановление покупок (App Store sandbox, Play test track, RevenueCat).
- Вход, подтверждение письма, сброс пароля и удаление аккаунта на живом Supabase.
- Офлайн-режим (не реализован).
- Скринридер (VoiceOver, TalkBack): метки заданы, но не слушались.
- Медленная сеть и потеря сети посреди запроса.
- Вебхук RevenueCat: проверка подписи, повторная доставка, отмена, истечение.
