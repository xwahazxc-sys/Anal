## Что нужно сделать владельцу

1. Создать проект Supabase, выполнить `supabase db push` (или вставить миграцию), затем `seed.sql`. Включить ежедневные резервные копии.
2. В Auth включить подтверждение email, добавить свой SMTP (Resend), задать адреса возврата. Для входа через Apple и Google: свои приложения разработчика.
3. Положить URL и anon-ключ в `app/.env.local`. Service role ключ в клиент не попадает.
4. Создать проект RevenueCat, привязать App Store Connect и Play Console, добавить вебхук на функцию с заголовком из `REVENUECAT_WEBHOOK_AUTH`; `supabase functions deploy revenuecat-webhook`.
5. В приложении на телефоне подключить SDK RevenueCat и вызывать `Purchases.logIn(<id пользователя Supabase>)`: вебхук находит пользователя по этому id. Эта часть кода пока не написана, она требует нативной сборки и аккаунтов магазинов. Кнопка «Восстановить покупки» обязательна для магазинов.
6. Распознавание текста на фото (`process_submission`) и загрузка фото в хранилище пока не сделаны: заявки принимаются с текстом, без фото.

## Известные ограничения

- Оценка в базе (`products.score`) считается при загрузке данных. Если формулу в `app/src/scoring.ts` изменить, нужно перегенерировать сид и пересчитать (`score_version`). Клиент считает оценку сам по составу, поэтому на карточке расхождения не будет, но подбор альтернатив опирается на значение в базе.
- Заявки пользователей (`submissions`) пока никто не публикует: нужен модератор или задача проверки.
- Задачи `recompute_scores`, `expire_premium`, `purge_deleted_users` из архитектуры не созданы: статус Premium выставляется вебхуком по дате окончания, а срок проверяется при каждом запросе (`premium_until > now()`), поэтому отдельная задача пока не нужна.
- Ограничение частоты запросов и защита регистрации задаются в панели Supabase Auth, в коде не заданы.
- `npm audit`: 23 замечания (16 высоких), все в транзитивных зависимостях инструментов Expo (braces, node-forge, uuid), а не в коде приложения. `npm audit fix --force` ломает версии SDK, поэтому не применялся. Перед выпуском повторить аудит.
