## Три списка (гипотезы, слабая база)

1. **Что не нравится** (в источниках фигурирует):
   - Один балл для всех, без контекста: оливковое масло, орехи, сыр и тёмный шоколад получают низкие оценки из-за жира и калорий.
   - Добавки снижают оценку, даже когда их количество мизерное (замечание World Cancer Research Fund по пересказу).
   - Ошибки в данных: пропавшие ингредиенты, дубликаты продуктов с разными оценками.
   - Платные подписчики, нашедшие ошибку, должны сами присылать информацию.
2. **Чего не хватает:** понятного объяснения, почему получился именно такой балл, и видимого результата после сообщения об ошибке. Названий конкретных запрошенных функций из отзывов у меня нет.
3. **Что не решено:** оценка под цели человека (диабет, спорт, аллергии) вместо одной шкалы. В Yuka есть фильтры предпочтений в Premium, но в источниках они не обсуждаются.

Все три списка: источников мало, это вторичные пересказы, прямых цитат нет. Считать их тонкими.

```
А. Для тех, кто не понимает, почему продукт получил свой балл,
   приложение показывает каждый вклад в оценку и правила, по которым она считается.
   Evidence: гипотеза, 3 вторичных источника (статьи), 0 отзывов.

Б. Для тех, кто нашёл ошибку в базе продуктов,
   приложение принимает сообщение и показывает статус его проверки.
   Evidence: гипотеза, 2 вторичных источника, 0 отзывов.

В. Для тех, кому важны цели, а не общий балл (диета, спорт, аллергии),
   приложение оценивает продукт под ваши цели.
   Evidence: слабая гипотеза, 1 вторичный источник, 0 отзывов.
```

Рекомендую **А** («оценка, которую можно проверить»): дёшево сделать, не требует чужих данных и совпадает с самым частым пунктом критики. Но это ставка без подтверждения отзывами: прежде чем строить бренд на ней, прочитайте 100 реальных отзывов из списка выше и поправьте выбор. Название и рекламу не связывайте с названием оригинала.
