# ComfyUI + Wan 2.2 — установка для новичка (Windows, RTX 5070)

## Что это вообще такое

- **ComfyUI** — бесплатная программа, которая запускает ИИ-модели на твоей видеокарте.
  Это как «плеер», только вместо фильмов он проигрывает нейросети. Работает в браузере, но всё считается у тебя на ПК.
- **Wan 2.2** — нейросеть, которая делает видео. Даёшь ей картинку и описание («граф спускается по лестнице»),
  она возвращает 5-секундный клип, где картинка оживает.
- **Модели** — это большие файлы (по 1–10 ГБ), «мозги» нейросети. ComfyUI без них ничего не умеет.

Тебе нужно: поставить ComfyUI → скачать модели (это делает скрипт) → один раз проверить, что видео получается.
Дальше Claude будет пользоваться этим сам через воркер.

**Нужно места:** ~40 ГБ под модели + ~10 ГБ под ComfyUI. Лучше на SSD.

---

## Шаг 1. Скачать ComfyUI (10 минут)

1. Открой страницу **github.com/comfyanonymous/ComfyUI/releases**.
2. В последнем релизе, в разделе **Assets**, скачай файл
   **`ComfyUI_windows_portable_nvidia.7z`** (около 2 ГБ).
3. Распакуй его в **`C:\`** — получится папка `C:\ComfyUI_windows_portable`.
   - Windows 11 распаковывает .7z сама: правый клик → «Извлечь все».
   - Если не получается — поставь бесплатный **7-Zip** (7-zip.org): правый клик → 7-Zip → «Распаковать здесь».

Устанавливать ничего не надо: внутри уже есть свой Python и всё для видеокарт RTX 50xx.

## Шаг 2. Первый запуск (5 минут)

1. Открой `C:\ComfyUI_windows_portable` и дважды щёлкни **`run_nvidia_gpu.bat`**.
2. Откроется чёрное окно, побегут строчки. Первый раз это 1–3 минуты.
3. Сам откроется браузер с адресом **http://127.0.0.1:8188** — это и есть ComfyUI (схема из прямоугольников).
4. **Чёрное окно не закрывай** — пока оно открыто, ComfyUI работает.

Если браузер не открылся — открой его сам и введи `127.0.0.1:8188`.

## Шаг 3. Дополнения (5 минут)

Для «облегчённой» версии Wan 14B нужно одно дополнение:
1. В ComfyUI справа вверху кнопка **Manager** → **Custom Nodes Manager**.
2. В поиске набери **`ComfyUI-GGUF`** → Install (автор city96).
3. Ещё найди **`ComfyUI-VideoHelperSuite`** → Install.
4. Нажми **Restart** внизу, подожди, обнови страницу браузера.

## Шаг 4. Скачать модели (одна команда, ~38 ГБ)

Скрипт сам скачает всё в правильные папки и докачает, если интернет оборвётся.
Открой **командную строку** (Пуск → набери `cmd` → Enter) и выполни:

```bat
cd C:\Anal\local-worker
python download_models.py "C:\ComfyUI_windows_portable"
```

(`C:\Anal` появится после шага 2 основной инструкции — `README.md`. Если папки ещё нет, сначала сделай тот шаг.)

Что скачается:

| Набор | Размер | Что это |
|---|---|---|
| **lite** — Wan 2.2 5B | ~18 ГБ | Быстрая версия: простые оживления картинок для Shorts. Легко помещается в 12 ГБ |
| **cinema** — Wan 2.2 14B (GGUF) + ускоритель LightX2V | ~28 ГБ (общий текстовый модуль не качается второй раз) | Кино-качество движения. Нужно **32+ ГБ оперативки** |

Если оперативки 16 ГБ — качай только быструю: `python download_models.py "C:\ComfyUI_windows_portable" lite`

Когда закончится — **закрой чёрное окно ComfyUI и запусти `run_nvidia_gpu.bat` снова**, чтобы он увидел модели.

## Шаг 5. Проверка: первое видео (10 минут)

1. В ComfyUI слева нажми **Templates** (Шаблоны) → раздел **Video**.
2. Выбери **«Wan 2.2 5B Video Generation»** (иногда называется *Wan2.2 TI2V 5B*).
3. Откроется схема. Если выскочит окно «missing models» — значит модель лежит не там; напиши Claude, что в нём написано.
4. Нажми синюю кнопку **Run** (внизу или вверху).
5. Через несколько минут справа появится видео. Получилось — всё работает. 🎉

Скорость, которую стоит ожидать на 5070: несколько минут на 5-секундный клип (первый запуск дольше — модели грузятся в память).

## Шаг 6. Автозапуск

Чтобы ComfyUI стартовал сам после включения ПК:
**Пуск → «Планировщик заданий» → Создать задачу** → вкладка «Триггеры» → «При входе в систему» →
вкладка «Действия» → «Запуск программы» → `C:\ComfyUI_windows_portable\run_nvidia_gpu.bat`.

## Если что-то пошло не так

| Что видишь | Что делать |
|---|---|
| Чёрное окно сразу закрылось | Обнови драйвер NVIDIA, перезагрузи ПК, запусти снова |
| `CUDA out of memory` | Закрой игры/браузер с видео; для 14B нужна оперативка 32+ ГБ |
| В браузере пусто | Подожди ещё минуту и обнови страницу |
| Любая другая ошибка | Скопируй последние 20 строк чёрного окна и пришли Claude |

Дальше: запусти воркер (`README.md`, шаги 5–7) — и Claude сможет ставить задания на видео сам.
