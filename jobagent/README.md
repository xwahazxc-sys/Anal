# jobagent

ИИ-агент: ATS-резюме под каждую вакансию + поиск/оценка вакансий + полуавтоматический отклик.

## Как это работает
1. `data/profile.yaml` — ваш мастер-профиль (факты). Агент ничего не выдумывает, только переупаковывает их.
2. `jobagent check` — детерминированная ATS-проверка (структура, даты, метрики, контакты).
3. `jobagent tailor vacancy.txt` — оценка совпадения, резюме (DOCX/MD, один столбец, без таблиц) и письмо под вакансию. Для LinkedIn/Indeed и любых сайтов без API: вставляете текст вакансии в файл (первая строка — название).
4. `jobagent hh-run` — поиск на hh.ru → скоринг → резюме → черновики. С `--send` каждый отклик требует вашего `y`; есть дневной лимит и журнал в SQLite (без дублей).

## Старт
```bash
cd jobagent && pip install -e '.[dev]'
cp .env.example .env && cp data/profile.example.yaml data/profile.yaml   # заполнить
jobagent check
jobagent hh-auth            # затем jobagent hh-auth --code ...  → токен в .env
jobagent hh-run             # dry-run
jobagent hh-run --send      # с подтверждением каждого отклика
```

## Безопасность и правила площадок
- Пароли не нужны и не передаются: hh.ru — через OAuth-токен, ключи — только в `.env` (в .gitignore).
- LinkedIn/Indeed запрещают автоматизацию, поэтому там только подготовка материалов, нажимаете вы.
- Хабр Карьера/SuperJob/Работа.ру — добавляются как модули в `sources/` по мере появления официального API.
